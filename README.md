# Find My Doctor For BD

বাংলাদেশের ডাক্তার অনুসন্ধান প্ল্যাটফর্ম।

## Tech Stack
- React + Vite + TypeScript
- Tailwind CSS
- React Router
- Lucide Icons

## Local Development
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Deployment
GitHub Pages via GitHub Actions (`.github/workflows/deploy.yml`).

## Data
Doctor data in `src/data/doctors.ts`. All entries are unverified seed data from public sources; verify before use.

## Medical Disclaimer
This is an informational platform, not medical advice.
